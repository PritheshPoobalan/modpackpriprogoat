# Contributing

Contributions to modpackpriprogoat are welcome. This document explains how to
submit changes to the repository.

## How to contribute

1. Fork the repository or create a branch from the main branch.
2. Make your changes. Do not delete existing content.
3. Test your changes on the target platform.
4. Commit your changes with a clear, conventional commit message, for example:

   docs: add installation instructions

   Do not use emojis in commit messages or file content. This is a public
   repository and commit messages must remain plain text.
5. Push your branch to your fork or repository.
6. Open a pull request or submit your changes for review.

## Commit message style

Use conventional commit prefixes such as docs, feat, fix, chore, style, refactor,
or build. Keep messages concise and avoid emojis.

## Code style

- Match the formatting of existing files.
- Add comments where behavior is not obvious.
- Keep documentation up to date when you change functionality.

## Reporting issues

Report bugs and suggest features in the repository issue tracker:
https://github.com/PritheshPoobalan/modpackpriprogoat/issues
